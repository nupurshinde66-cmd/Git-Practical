\# Git and GitHub – Version Control Practical



\## Aim

To perform version control operations using Git and GitHub.



\## Objectives

\- Git installation and configuration

\- Repository creation

\- Branching and merging

\- Managing project source code

\- Collaboration using GitHub

\- Maintaining version history

\- Resolving merge conflicts

\- Documentation of workflow



\## Tools Used

\- Git

\- GitHub

\- Visual Studio Code

\- Java



\## Steps Performed

1\. Installed and configured Git.

2\. Created a GitHub repository.

3\. Cloned the repository into the local system.

4\. Created Java source code.

5\. Added, committed and pushed source code.

6\. Created a feature branch.

7\. Merged feature branch into main branch.

8\. Maintained version history using Git log.

9\. Resolved merge conflicts.

10\. Documented the version control workflow.



\## Conclusion

Successfully performed Git and GitHub version control operations, including repository creation, branching, merging, version history management and conflict resolution.
